# 🍽️ Zomato Data Analysis Project Using Python 🐍

Welcome to the **Zomato Data Analysis Project**! 📊\
This project focuses on analyzing Zomato restaurant data using
**Python** to discover useful insights about customer orders, restaurant
types, ratings, spending patterns, and order modes. 🔍

## 🎯 Project Objective

The main objective of this project is to explore the Zomato dataset and
answer important business-related questions using **Data Analysis with
Python**. 📈

## ❓ Questions to be Answered

### 1️⃣ Restaurant Type 🍴

**What type of restaurant do the majority of customers order from?**

We will identify the restaurant type that receives the highest number of
customer orders. 🏆

### 2️⃣ Votes by Restaurant Type 🗳️

**How many votes has each type of restaurant received from customers?**

We will analyze the total number of customer votes received by each
restaurant type. 📊

### 3️⃣ Restaurant Ratings ⭐

**What are the ratings that the majority of restaurants have received?**

We will determine the rating range/score that is most common among the
restaurants. ⭐📈

### 4️⃣ Average Spending of Couples 💑💰

**Zomato has observed that most couples order most of their food online.
What is their average spending on each order?**

We will calculate the **average amount spent per order by couples** who
primarily order food online. 🛵🍔

### 5️⃣ Online vs Offline Ratings 🌐🏪

**Which mode (online or offline) has received the maximum rating?**

We will compare the ratings received by **online** and **offline**
orders to determine which mode has the higher rating. 🏅

### 6️⃣ Restaurant Type with More Offline Orders 🏪📦

**Which type of restaurant received more offline orders, so that Zomato
can provide customers with some good offers?**

We will identify the restaurant type with the highest number of
**offline orders** and use the result to suggest where Zomato could
provide special offers. 🎁🔥

## 🛠️ Technologies Used

## 📌 Expected Outcome

After completing the analysis, we will obtain useful insights into:

-   🍽️ Most popular restaurant types
-   🗳️ Customer voting patterns
-   ⭐ Restaurant rating distribution
-   💰 Average spending of couples
-   🌐 Online vs offline order performance
-   🏪 Restaurant types with more offline orders

These insights can help **Zomato** understand customer behavior and make
better business decisions. 🚀📊
